UNOへの4-way書き込み

BLHeliSuite32で使うArduino 4-wayインターフェースを、UNO R3にブラウザから書き込むためのページです。

← Pico用UF2配布ページへ戻る

対応範囲と注意

対象：Arduino UNO R3（ATmega328P、通常のOptiboot 115200bps）だけ。 UNO R4 / Mega / Leonardo / RP2040 / Picoや、旧ブートローダーのUNO互換機には対応しません。

ブラウザのWeb Serial APIを利用するのでWindowsのChromeかEdgeで、このHTTPSページを開いてください。 USBアクセスはブラウザが許可したCOMポートに限られます。選択したHEXは外部サーバーへ送信されません。

プロペラを取り外し、書き込み中はUNOにESCを接続しないでください。UNO内の既存スケッチは消去されます。 接続先の基板とHEXが正しいことを確認してください。

1. Arduino用4-way HEXを選ぶ

BLHeliSuite32を展開したフォルダから、UNO（ATmega328P）用 Arduino 4way-interfaceの .hex ファイルを選んでください。Nano用、BLHeli ESC本体用のHEXは選ばないでください。

著作権・配布条件を確認できないファームウェアはこのサイトに同梱していません。 ファイルはご自身で正規入手したものを選択してください。

ファイル未選択

2. UNO R3をUSBでつなぐ

  1. Arduino UNO R3だけをPCのUSBポートに接続します。ESC側の電源・信号線は外してください。
  2. デバイスマネージャーでUNOのCOM番号を確認します。他のシリアルモニタを閉じます。
  3. 下のボタンを押し、Chrome / Edgeに表示されたUNOのCOMポートを選択します。
  4. UNOのマイコン識別子を確認後、HEXを書き込み、各ページを読み戻して照合します。

待機中

ボタンを押しても自動的に書き込みは始まりません。COMポートの選択が必要です。 途中で失敗した場合は、UNOの接続を確認して再実行できます。

3. ESCの設定を確認する

このページが書き込むのはArduino UNO内のインターフェースだけです。 ESC本体の設定読み出しや Auto Telemetry の変更はまだ行いません。

  1. 書き込み成功後、UNOをUSBから一度抜いて再接続します。
  2. UNO側の4-wayインターフェースに合うピン割り当てを確認し、ESCの信号とGNDを接続します。
  3. プロペラを外した状態で、ESCには別電源を使用します。
  4. BLHeliSuite32で BLHeli32 Bootloader (4way-if) を選んで Read Setup を実行します。

BLHeli_32用ESCを書き換える機能は実装していません。設定確認時にESCのファームウェア更新は不要です。
