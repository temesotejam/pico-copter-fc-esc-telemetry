飛行制御ソース一式（ZIP）

Gitリポジトリ全体ではなく、飛行制御プログラム、各種ヘッダ、PIO、CMake設定、Eigen 3.4.0のヘッダとライセンス、ビルド手順だけをまとめたZIPです。研究室や手元のPCへ展開して、そのまま編集・ビルドできます。

飛行制御ソース ZIPをダウンロード

別途必要なもの：Raspberry Pi Pico SDK 2.3.0、ARM GCC、CMake（Ninja推奨）。EigenはZIPに含まれるため、追加ダウンロード不要です。

展開した pico_copter フォルダ内で PORTABLE_BUILD.md の手順に従ってください。ゲイン調整を繰り返す際は、同じ build フォルダで増分ビルドできるので、毎回全体をコンパイルする必要はありません。

書き込み

  1. 使用する基板（Pico / Pico 2）を選び、対応するUF2をダウンロードします。
  2. 基板のBOOTSELを押したままUSB接続します。
  3. 表示されたUSBドライブに、選んだ基板用のUF2をコピーします。
  4. コピー後、基板が自動的に再起動します。
  5. まずはプロペラなしでDShot300停止指令とモータ対応を確認してください。
